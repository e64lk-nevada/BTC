# BTC Signal Only — Render + iPhone

Це мобільний веббот для **сигналів BTC UP/DOWN на Polymarket 5m**. Він не підписує транзакції, не торгує, не потребує приватного ключа чи API-ключів.

## Запуск через Render з iPhone
1. Розпакуй ZIP та завантаж папку в новий GitHub-репозиторій (можна через Safari/GitHub).
2. Відкрий https://render.com та увійди.
3. New → Blueprint, підключи репозиторій з файлами цього проєкту.
4. Render прочитає `render.yaml`; створи Web Service.
5. Дочекайся статусу Live і відкрий адресу `https://...onrender.com` у Safari.
6. Safari → Поділитися → На початковий екран — матимеш іконку вебзастосунку.

## Налаштування Render
`POLL_SECONDS` — частота перевірки, за замовчуванням 15 секунд.
`MIN_SCORE` — мінімальна оцінка сигналу, за замовчуванням 0.72 (діапазон 0..1).

## Джерела та логіка
- Binance public REST klines (BTCUSDT, 1m) — ціна, імпульс і обсяг.
- Polymarket Gamma API — поточний 5-хвилинний ринок.
- Polymarket CLOB — книга заявок для UP-токена.
- Фільтр: узгодження імпульсу 1/3/5 хв, EMA-тренд, RSI, відносний обсяг, ціна UP та спред.

## Важливо
- Сигнал `UP`/`DOWN` означає напрямок для самостійної перевірки, не команду автоматичної купівлі.
- `WAIT` — пропустити вхід. При помилці джерел бот також переходить у WAIT.
- Порогова модель — початкова евристика, не доведена прибуткова стратегія. Перевіряй її в paper trading щонайменше кілька тижнів, веди статистику точності й не ризикуй коштами, які не можеш втратити.
- Render free instances можуть засинати після простою; для постійної роботи потрібен план, який не засинає. SQLite на файловій системі Render може скидатися під час redeploy/restart; для довготривалої історії додай Render Persistent Disk або PostgreSQL.
- Цей проєкт не використовує ключів Polymarket і не має функції live execution.
